# PSMG-Compendium — Parkside Motel Guest Information

A digital compendium for Parkside Motel Geelong guests, accessed via QR code in each room.

## File

- **`index.html`** — Single-page static guest information guide covering check-in/check-out times, Wi-Fi, house rules, parking, air-conditioning, TV, local essentials, and emergency contacts.

## Hosting

Deployed via [Netlify](https://www.netlify.com/) — simply connect this repository to Netlify and it will serve `index.html` automatically.

To serve locally, open `index.html` directly in any browser.
